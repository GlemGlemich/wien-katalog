# Работа с репозиторием

После каждого завершённого изменения приложения запускайте подходящие проверки, создавайте коммит и отправляйте его в `origin/main`. Если отправка невозможна, сохраняйте локальный коммит и сообщайте пользователю причину.

Не добавляйте в Git локальную базу `data/catalog.sqlite3`, кэш буклетов, файлы состояния обновления, ключи доступа и другие секреты. Репозиторий должен оставаться приватным, пока пользователь явно не попросит изменить видимость.
